Sobre o Projeto

O projeto RAG - Relatórios Criminais visa desenvolver um sistema baseado em Retrieval-Augmented Generation (RAG) para a gerar automaticamente relatórios criminais a partir de processos já concluídos. O sistema será alimentado por processo crime já existentes e utilizará técnicas de prompt engineering para sumarizar os atos mais relevantes.

Este projeto é uma colaboração entre o ISEL e a Polícia Judiciária, com o objetivo de modernizar e agilizar a produção de relatórios criminais.
